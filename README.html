README – Einzelbrief-Ersteller (Python)

GUI-basierter Einzelbrief-Ersteller mit DOCX-Export (DIN-ähnlicher Fensterbrief), Arial, Falz- & Lochmarken.

Dieses Programm ist ein GUI-basierter Einzelbrief-Ersteller. Es erzeugt Word-Dokumente (DOCX) in einer festen Struktur mit:

  • Fensterkuvert-Adresse (Absender klein + Empfänger im Fenster)
  • Datum rechts, Betreff, Anrede, Text, Grußformel, Signatur
  • Falzmarke und Lochmarke links
  • Schrift: Arial

Voraussetzungen

1) Python

  • Python ≥ 3.10 empfohlen
  • Getestet mit Python 3.10 / 3.11 / 3.12

Download: python.org/downloads

Windows-Hinweis: Bei der Installation bitte “Add Python to PATH” aktivieren.

python --version

2) Benötigte Python-Pakete

Das Programm benötigt genau ein externes Paket:

pip install python-docx

Verwendete Standardbibliothek (bereits in Python enthalten):

  • tkinter (GUI)
  • datetime
  • os

Test:

python -c "import docx; print('python-docx OK')"

Programm starten

Windows

macOS / Linux

Ausgabe

Das Programm exportiert DOCX-Dateien, kompatibel mit:

  • Microsoft Word
  • LibreOffice Writer
  • OnlyOffice

Hinweise

  • Falz-/Lochmarken sind als VML-Objekte im Header eingebettet. In Word werden sie korrekt dargestellt und gedruckt.
  • Je nach Zoom/Ansicht kann die Darstellung leicht abweichen – für den Druck ist das i.d.R. stabil.
  • Positionen sind im Skript mm-genau einstellbar (z.B. Fenster links/oben, Falz-/Lochmarke).

Typische Anpassungen: “Fenster 3 mm zu tief” → mm-Wert erhöhen/verringern, “Alles 2 mm weiter rechts” → linken Offset anpassen.
